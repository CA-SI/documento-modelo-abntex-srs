# PDF de demonstração versionado

## Objetivo

Publicar o modelo revisado e um PDF que permita conhecer o documento sem
instalar as ferramentas de compilação, conforme solicitação do autor.

## Critérios de aceite

- Versionar somente `exemplos/srs-demonstracao.pdf` entre os PDFs gerados.
- Produzir a demonstração a partir das fontes verificadas pelo `make check`.
- Disponibilizar link direto no README e comando para atualizar a demonstração.
- Preservar os requisitos, contratos, diagramas e os arquivos de referência.
- Fazer commit assinado com a identidade e a chave exigidas e publicar em
  `origin/master`, após conferir o estado remoto.

## Fora de escopo

Alterar o conteúdo da especificação, publicar arquivos recebidos do autor,
versionar auxiliares de compilação ou realizar push forçado.
